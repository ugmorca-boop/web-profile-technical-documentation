# Decision records
- **D1** Next.js with embedded Payload CMS: one repo, one language, one deployable unit.
- **D2** Invite-only passwords instead of SSO. UGM SSO may need IT approval; the account model is login-method independent so SSO can be added later.
- **D3** Business rules as pure functions in `src/lib`, so they are easy to test.
- **D4** Article bodies stored as structured rich text, not raw HTML, to reduce stored XSS risk.
- **D5** Append-only audit log, written only by server code.
- **D6** pnpm only, pinned through Corepack, one lockfile, `--frozen-lockfile` in CI and Docker.
Add a new file per decision from now on: context, decision, alternatives, consequences, date.
