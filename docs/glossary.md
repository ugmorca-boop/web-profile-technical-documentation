# Glossary
One definition per term, used the same way on every page. Add terms as content is written.
| Term | Definition |
|---|---|
| ROV | Remotely operated vehicle: an underwater robot controlled from the surface |
| Thruster | A motor with a propeller that moves the vehicle |
| Buoyancy | The upward force of water on the vehicle |
| Hull | The main body that protects the electronics |
| Depth hold | A control mode that keeps the vehicle at a set depth |
